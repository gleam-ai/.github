# Support

## How to get help

| Need | Where |
| --- | --- |
| Bug report | GitHub Issues (Bug report template) in the product repo |
| Feature idea | GitHub Issues (Feature request template) |
| Usage / design question | GitHub Discussions (when enabled) or the Question issue template contact link |
| Security vulnerability | [SECURITY.md](./SECURITY.md) — private only |
| Docs gap | Documentation issue template |

## Product entry points

- **Gleam** (desktop AI agent): https://github.com/gleam-ai/Gleam
- Organization profile: https://github.com/gleam-ai
- Website: https://gleam.wangjn.top/

## What we can and cannot promise

- Maintainers triage issues labeled `needs-triage` as capacity allows.
- `good first issue` and `help wanted` are good entry points for new contributors.
- There is no guaranteed SLA for general support questions (security has its own SLA).

## Before opening an issue

1. Search existing issues and discussions.
2. Confirm you are on a supported version (latest release or default branch).
3. Include OS, version/commit, and minimal reproduction for bugs.
