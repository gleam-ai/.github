# gleam-ai/.github

Org-wide community health files, issue/PR templates, reusable workflow templates, and engineering defaults for [@gleam-ai](https://github.com/gleam-ai).

This repository powers:

| Path | Purpose |
| --- | --- |
| [`profile/README.md`](./profile/README.md) | Organization profile (shown on https://github.com/gleam-ai) |
| [`CONTRIBUTING.md`](./CONTRIBUTING.md) | Contribution guide (commits, PRs, DCO-style sign-off) |
| [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 |
| [`SECURITY.md`](./SECURITY.md) | Private vulnerability reporting + SLA |
| [`SUPPORT.md`](./SUPPORT.md) | How to get help |
| [`GOVERNANCE.md`](./GOVERNANCE.md) | Roles, maintainers, decision making |
| [`.github/ISSUE_TEMPLATE/`](./.github/ISSUE_TEMPLATE/) | Shared issue forms |
| [`.github/PULL_REQUEST_TEMPLATE.md`](./.github/PULL_REQUEST_TEMPLATE.md) | PR checklist |
| [`.github/workflow-templates/`](./.github/workflow-templates/) | Reusable workflow starters |
| [`.github/workflows/`](./.github/workflows/) | Hub CI + automation for this repo |

Product repositories (for example [gleam-ai/Gleam](https://github.com/gleam-ai/Gleam)) own their own CI that matches their stack; this hub holds the org defaults.

## Teams

| Team | Role |
| --- | --- |
| [`@gleam-ai/maintainers`](https://github.com/orgs/gleam-ai/teams/maintainers) | CODEOWNERS, releases, governance |
| [`@gleam-ai/reviewers`](https://github.com/orgs/gleam-ai/teams/reviewers) | Default PR reviewers |
