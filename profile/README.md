# gleam-ai

**gleam-ai** builds local-first open-source tools. Our flagship product is **[Gleam](https://github.com/gleam-ai/Gleam)** — a desktop AI agent (~10MB single binary, zero third-party Go dependencies) for file organization, task planning, scheduled execution, with built-in tools and MCP extensions. Your data stays on your machine.

- Organization: [@gleam-ai](https://github.com/gleam-ai)
- Product: [gleam-ai/Gleam](https://github.com/gleam-ai/Gleam)
- Site: [gleam.wangjn.top](https://gleam.wangjn.top/)
